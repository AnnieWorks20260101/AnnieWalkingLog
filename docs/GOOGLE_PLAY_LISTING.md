## アプリの詳しい説明（第1版）

```
🐾 Annie Walking Log — 家族みんなで、いつものお散歩を残すアプリ

大切なワンちゃん・ネコちゃんとのお散歩を、距離・時間・ルートと一緒に記録し、家族で共有できるアプリです。
「今日、どれくらい歩いた？」「いつうんちをした？」—— 散歩のあと、スマホを開けばすぐ振り返れます。

■ こんな方におすすめ
・家族やパートナーとペットのお世話を分担している方
・複数のペットを飼っている方
・散歩の習慣や健康状態を、記録として残したい方
・実家のペットの様子を、離れていても共有したい方

■ 主な機能

【お散歩の記録】
・「スタート！」で記録開始。GPS でルート・距離・時間を自動計測
・画面を閉じたあとも記録を継続（位置情報の「常に許可」が必要です）
・お散歩中に、うんち 💩 やおしっこ・休憩などのマークを地図上に残せます
・カスタムボタンで、よく使うアイコン（水・休憩・肉球など）に変更可能
・複数のペットを同時に選んで、1回のお散歩として記録

【記録の見返し】
・お散歩一覧で、日付・距離・時間・ペット別に確認
・地図上でルートとマークを表示
・メモを追加して、その日のできごとを残せます
・記録グラフで、距離・時間・時速・うんち回数などを期間別に表示

【ペット管理】
・お名前、種類、お誕生日、お迎え日、グループ（自宅・実家など）を登録
・写真付きプロフィール
・一覧の並び順は自由に変更（お散歩画面の表示順にも反映）

【家族で共有】
・「家族コード」で家族グループに参加
・同じ家族のメンバー全員が、ペット情報とお散歩記録を共有
・お散歩終了時、家族に通知（プッシュ通知）
・LINE などで家族コードを送って招待できます

【写真】
・お散歩中に撮影した写真を記録に紐づけ（プランにより枚数・画質が異なります）
・Wi‑Fi / モバイル回線の設定に応じて、クラウドへアップロード

【データのエクスポート】
・家族のペット・お散歩記録を JSON 形式で書き出し（サマリー版 / フル版）

【その他】
・日本語 / English 対応
・文字サイズ・時間表示（12/24時間）の変更
・よくある質問（FAQ）をアプリ内に掲載

■ アカウントとプラン

・ゲストログイン … お試し利用（記録は直近10回までなど制限あり）
・無料会員登録 … メール、Google、Apple で登録。データをクラウドに保護
・プレミアムプラン … 家族の誰か1人が加入すると、同じ家族コードの全員がプレミアム機能を利用可能（全期間の記録閲覧、比較グラフ、写真枚数アップなど）

※ プレミアムの料金・購入は順次提供予定です。詳細はアプリ内のプラン比較をご確認ください。

■ ログイン方法

・ゲスト（お試し）
・メールアドレスとパスワード
・Google アカウント
・Apple ID（対応端末）

■ 位置情報について（重要）

お散歩ルートを正確に記録するため、位置情報の利用許可が必要です。
画面を閉じた状態でも記録を続けるには、「常に許可」の設定をお願いします。
取得した位置情報は、お散歩のマップ作成と距離計算のみに使用し、広告配信や第三者への提供には使用しません。

■ 動作環境

・インターネット接続が必要です（記録の保存・家族との共有）
・GPS（位置情報）が利用できる端末
・一部の Android 端末では、バッテリー最適化の設定変更が必要な場合があります（アプリ内ガイドあり）

■ お問い合わせ

アプリ内「設定」→「サポートへ連絡」からご連絡いただけます。

大切な家族の、いつものお散歩を。
Annie Walking Log で、今日の1歩を残しませんか。🐾
```
