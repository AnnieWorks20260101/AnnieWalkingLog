## 第２条（ユーザー登録）

1. 本サービスの利用を希望する者は、本規約およびプライバシーポリシーを遵守することに同意し、運営者の定める方法に従い登録または利用開始を行うものとします。
2. ユーザーは、次のいずれかの方法で本サービスを利用できます。
   - **ゲスト（匿名）利用**：アカウント登録なしで利用を開始する方法
   - **会員登録**：メールアドレスおよびパスワードによりアカウントを作成する方法
   - **Google アカウントによるログイン**：Google が提供する認証サービスを利用してログインまたは会員登録する方法
   - **Apple ID によるログイン（Sign in with Apple）**：Apple が提供する認証サービスを利用してログインまたは会員登録する方法（対応端末・OS）
   - **家族への参加**：他のユーザーから共有された家族コードを入力して、同一の家族グループに参加する方法
3. ゲスト利用の場合、端末の変更やアプリの再インストール、ログアウト（データ放棄）等により、記録データにアクセスできなくなる場合があります。データの継続的な保護のため、会員登録を推奨します。
4. ユーザーは、家族コードを第三者に共有する場合、共有先が信頼できる相手であることを自己の責任で確認するものとします。家族コードを知る者は、当該家族グループ内の記録（ペット情報、お散歩記録、写真等）を閲覧できる場合があります。
5. 運営者は、登録希望者または利用希望者が以下のいずれかに該当すると判断した場合、登録または利用を拒否することがあり、その理由について一切開示義務を負いません。
   - 登録事項の全部または一部につき虚偽、誤記または記載漏れがあった場合
   - 過去に本規約違反等により利用停止措置を受けた場合
   - その他、運営者が登録または利用を適当でないと判断した場合
6. 本規約への同意については、同意日時および本規約の版（バージョン）を、端末内およびクラウド（Firebase）上のユーザー情報に記録します。本規約を改定した場合（誤字修正のみを除く）、アプリ起動時またはログイン時に、改定後の本規約への再同意をお願いすることがあります。同意いただけない場合は、ログアウトして利用を終了できます。

1. ユーザーは、運営者所定の手続により、本サービスから退会し、自己のアカウントを削除することができます。

2. 会員が通常のログアウトを行った場合、クラウド上のデータは削除されず、次回ログイン時に再度アクセスできます。
3. アカウント削除またはゲストのデータ放棄にあたり、運営者はユーザーのデータを削除します。ただし、家族グループに他のメンバーが残っている場合、家族共有のペット情報・お散歩記録等は、当該家族の他メンバーが利用するため残る場合があります。
4. ユーザーは、設定の「データをエクスポート」機能等により、自己のデータを JSON 形式で書き出すことができます。
